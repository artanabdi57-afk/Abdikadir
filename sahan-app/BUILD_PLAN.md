# Sahan Core Build Plan

## Product principle
- Learn/Buy is the default experience.
- A user has one account and can become a creator later.
- Courses and standalone lessons are separate sellable products.
- Content moves through draft, published, unpublished, and archived states.

## Build order
1. Data model and Supabase schema
2. Authentication and profiles
3. Buy/Discover marketplace
4. Creator onboarding and studio
5. Course curriculum builder
6. Standalone lesson publishing
7. Enrollment and access
8. Learning player and progress
9. Orders and payments
10. Communities, live events, certificates, analytics

## Definition of done for the core
A user can sign up, browse published products, enroll in a free course, purchase-ready products can be represented as orders, creators can create draft content, publish it, and learners can access only content they own or that is free.
